# Portfolio — Chandra Sunarseto

**Live site:** https://seenchan27.github.io/Portfolio/

My personal portfolio as a Game Designer & Technical Designer — 10+ years across mobile, PC, and multiplayer titles, from QA at Gameloft to Lead Designer, currently building AI-assisted level tooling at Tripledot Studios.

## What's in here

- **Hand-built single-file site** — vanilla HTML/CSS/JS, no frameworks, no build step. The whole site is `index.html`.
- **11 projects** with click-to-open design breakdowns: each one is a set of *Problem → Choice → Result* decision cards instead of a wall of text.
- **A hidden mini-game.** Click the amber dot in the logo. It's a tiny physics puzzle built on the same "one block, many behaviors" philosophy as my Steam release, [BAL Solid](https://store.steampowered.com/app/1365630/BAL_Solid/) — 70 levels, 100% positive reviews, shipped solo.
- An ambient physics ball in the hero that politely avoids your cursor.
